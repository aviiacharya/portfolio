Current Research
Thesis / BSM Search

VLQ Pair Production via S0 → γγ

Searching for pair-produced vector-like top quarks decaying through a new neutral scalar in the single-lepton final state at 13 TeV. The diphoton mass resonance is the primary discriminant.

This channel is unexplored by existing VLQ searches. I led the end-to-end pipeline from Monte Carlo signal production through BSM decay characterization to resonance-based discrimination, with planned ML-based signal extraction.

Run 3 / Quantum Information

Entanglement in Boosted tt̅ Production

Measuring quantum entanglement at 13.6 TeV using spin correlations via the D coefficient, with a ParticleNet-based flavor tagging approach to boost spin analyzing power.

Built a columnar analysis framework processing terabyte-scale Run 3 data with multi-category event selection (AK8 top-tagging, b-jet classification), automated MC normalization, and Data/MC validation at 26.67 fb-1.
